    Pesquisa

    Relacional: combine nome, mãe, pai, CPF, telefone, CNPJ, endereço… em qualificações extraídas dos autos e nas bases de consulta. Clique em um valor para cruzá-lo. Bases de consulta servem só para pesquisa — não são fonte do relatório.

    A situação de mandados e cautelares é uma interpretação automática do texto de origem, a conferir; ela não comprova vigência. Confira sempre no sistema oficial.

    Tarefas

    Exportar banco de dados

    Pacote ZIP estruturado (com verificação de integridade) para backup ou para abrir em outro computador. Contém dados sigilosos: guarde em local autorizado.

    Pacotes gerados

    Importar banco de dados

    Envie um pacote exportado pela Central. Os arquivos são verificados; casos novos são acrescentados e casos existentes não são sobrescritos.

    Bases de consulta / dados de investigados

    Excel, CSV, Word, PDF, TXT ou texto colado (ex.: Muralha Paulista, fichas de sistemas). O sistema reconhece qualificação (nome, mãe, pai, CPF, RG, telefone, endereço, empresa, placa) e antecedentes (processos/IP/TC, BOs, mandados de prisão, medidas cautelares). Somente pesquisa — nunca fonte do relatório.

    Colar texto

    Cole a ficha copiada de outro sistema. Linhas no formato “Campo: valor” (Nome:, Mãe:, CPF:…) são reconhecidas; cada “Nome:” inicia um novo registro.

    Relatórios de referência

    Relatórios já elaborados (seus ou de colegas) para calibrar o estilo. Peso 5 = modelo exemplar. Usados só como exemplo de estrutura e estilo.

    Inteligência artificial — agentes de plantão

    Os botões de IA (na ficha do caso) criam um pedido na fila. O primeiro agente de plantão ocioso e aprovado executa, sem internet e usando somente os documentos do caso. Agentes: sessões de chat guiadas pelo PROMPT-AGENTE-PLANTAO.md (Claude, Codex, Antigravity) ou automáticos pelo ferramentas\Agente de plantao.bat. Agente novo só trabalha depois de aprovado pelo administrador.

    Perfis e permissões

    Marque o que cada perfil pode fazer. O Administrador sempre tem acesso total.

    Acesso pela rede local

    Ao salvar, feche e abra a Central de novo. Na primeira vez o Windows perguntará se libera o acesso no firewall: autorize apenas “Redes privadas/domínio”. Confirme a política com o setor de TI da unidade. Nos outros computadores, o navegador mostrará um aviso de certificado (autoassinado) na primeira vez.
