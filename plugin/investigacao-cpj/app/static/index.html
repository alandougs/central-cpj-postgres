    CONFIGURAÇÕES — processamento por agente ou por API

    Define quem executa os botões de IA e a esteira por padrão: agente de plantão (sessão de chat ou CLI local) ou API dos provedores cadastrados abaixo. No modo automático, tenta Claude, GPT, Gemini e depois os demais provedores ativos, avançando quando uma chamada falha. Na API, cada modelo recebe como instruções o AGENTS.md, os procedimentos, os papéis dos agentes (analista-documental, analista-financeiro, revisor) e as skills do plugin, mais o texto que você escrever aqui. Atenção ao sigilo: o conteúdo extraído do caso pode ser enviado a mais de um provedor ativo até uma chamada funcionar (exceção autorizada à regra 6; cada uso fica na auditoria). Chaves e modelos ficam no cartão logo abaixo.

    Chaves de API e Modelos de LLM (GPT, Claude, Gemini, Groq, OpenRouter, NVIDIA e outros)

    Cadastre as chaves de API e modelos para acionamento direto ou agentes de IA. As chaves são salvas localmente neste computador (config\chaves_llm.json). Consultar modelos envia apenas a chave e metadados ao provedor, sem autos. Escolha na lista ou digite um identificador. Sem escolha preenchida, um modelo equilibrado retornado pela API é sugerido no formulário; confira e clique em Salvar. A consulta não salva nem ativa o provedor.
