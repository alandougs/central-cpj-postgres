# Critérios para escolher um modelo

Registre por tarefa: qualidade de extração e citação, janela de contexto útil, capacidade de usar ferramentas, latência, custo efetivo, idioma, controles de dados e disponibilidade local. Teste com conjunto fictício representativo e meça erros de transcrição, alegações sem fonte e revisões humanas necessárias.

Modelos, preços, limites e políticas mudam. Antes de recomendar uma versão ou compartilhar material sensível, confira documentação oficial atual e regras do órgão. O uso de Codex, Claude Code e Antigravity por assinatura não implica que chamadas por API estejam incluídas. Considere Ollama/modelos locais quando a política de dados e a máquina disponível favorecerem processamento local.
